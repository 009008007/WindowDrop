WINDOWDROP — PREVIEW FOR YOUR MAC

1. Open WindowDrop.app (Apple Silicon, macOS 15+).
2. Choose file → Start sharing.
3. Send the link and code to your friend. They only need a browser.
4. Close the WindowDrop window to stop sharing and quit.

No Python installation. No login item. No cloud file copy.
Your Mac must stay awake and connected while sharing.
